# first-pr-practice

A small collection of string utility functions, used to practice contributing via pull requests.

## Functions

- `capitalize(str)` — uppercases the first letter of a string.
- `reverse(str)` — reverses a string.
- `isPalindrome(str)` — checks whether a string reads the same forwards and backwards.

## Running tests

```bash
node test/stringUtils.test.js
```
